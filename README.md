# Installation
1. Download the repository 
2. Using Python 3.9.25, install dependencies from ```requirements.txt```
2. Download and install foldseek from https://github.com/steineggerlab/foldseek
3. Download and install BLAST standalone from https://www.ncbi.nlm.nih.gov/books/NBK52640/
4. Activate the prepared environment
5. Run the web application with ```flask --app app run```
